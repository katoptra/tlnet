tlnet


Last update: .

tlnet is a daily mirror of CTAN/systems/texlive/tlnet on Cloudflare R2. tlmgr installs and updates TeX Live from this directory. The mirror has the full subtree: all the platforms, the documentation and the sources. From the other parts of CTAN, the mirror has only the timestamp file at the root.

How to use

TeX Live and TinyTeX use tlmgr. To use this mirror, give these two commands:

tlmgr option repository https://tlnet.katoptra.org/systems/texlive/tlnet/
tlmgr update --self --all

For a new installation, give the same URL to the installer:

install-tl -repository https://tlnet.katoptra.org/systems/texlive/tlnet/

To set tlmgr back to the mirror rotation of CTAN, use tlmgr option repository ctan.

The paths are the same as the paths on CTAN. Thus, this host can replace the host of a CTAN mirror URL. The mirror copies the TeX Live release that upstream has. When upstream moves to the next release, the mirror also moves to it.

How it works

Each day, a GitHub Actions job copies the changes in the tlnet directory to R2. Before the job publishes a file, it verifies texlive.tlpdb, the installers and the updaters with their SHA-512 checksums and GPG signatures. For these checks, the job uses the TeX Live key that the pipeline pins. The job also verifies each package container with its checksum.

The landing page is the only step that this mirror adds. Each other step is a verb of the toolbox or of the rsync engine in katoptra/lib. Taskfile.yml gives the sequence of the steps.

Is it fresh?

Each hour, the master of CTAN writes its clock to timestamp, at the root of CTAN. Each run copies this file to the root of this mirror. Thus, the file shows the clock of the master at the last run (year-month-day-hour-minute, UTC):

curl -s https://tlnet.katoptra.org/timestamp

If this clock is more than 24 hours before a run, that run stops with an error.

This mirror and the mirror rotation

The default repository of tlmgr is the mirror rotation of CTAN. Each request can go to a different volunteer mirror. Thus, these problems can occur:

  • The mirror is not available.
  • The mirror has a slow connection.
  • The mirror uses a TLS version that is not the newest.
  • The last update of the mirror is some days before the last update of CTAN.

With this mirror, each request goes to one source for TeX Live updates. Cloudflare's network serves this source.
